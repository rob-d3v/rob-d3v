#### What I build

- **Talking avatars** — *Ania*: an animated `.ania` avatar format with lip-sync, a player for desktop and web, and a marketplace to sell and buy avatars.
- **Voice** — offline wake words and local Piper voices that run on the device, no audio leaving it.
- **AI agents & MCP** — agents that answer from a company's own knowledge base and reach real systems (calendar, orders, CRM) over MCP.
- **SaaS** — payments, generative AI and WebRTC products running in production on self-hosted infrastructure.
